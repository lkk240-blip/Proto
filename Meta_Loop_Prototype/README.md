# Nest(가칭) 메타 루프 프로토타입

`index.html` 하나를 브라우저로 열면 바로 실행됩니다(빌드·서버 없음).
밸런스·콘텐츠 수치는 전부 파일 상단 `CONFIG` 객체에 있습니다.

## 진행 단계
- [x] ① 데이터 모델과 `CONFIG`, 시드 난수, 저장/내보내기/불러오기, 창고 화면, 디버그 패널 골격
- [x] ② 런 스텁(확률/진행자 모드), 출동 준비, 결과 정산, 사건 태그
- [x] ③ 두더지 굴 맵 카드 보드(유형별 생성·추적 표식·불운 보정), 판돈, 알 도감
- [x] ④ 거점: 메인 거점 단계, 생산 건물, 부화장, 몬스터 노동(자동/수동), 생산 틱
- [x] ⑤ 공용 잔성장 모듈(구매·효과·전체 끄기)과 모듈 토글 표시

## 임시로 정한 값
수치는 전부 임시값입니다. 명세가 비어 있어 정한 규칙만 정리합니다.

### 데이터·저장
- 세이브 = `{ world, log }`. `world`가 월드(호스트) 공용 자산 전체이고, `world.members`에 함께 쓰는 플레이어 목록, `world.activeMember`에 현재 조작자를 둡니다. 알 획득자·몬스터 소유 표시·행동 기록에 조작자 id가 찍힙니다(권한 구분은 없음).
- 난수는 스트림 4개(`board`·`run`·`hatch`·`misc`)로 나눴습니다. 판돈으로 보드를 다시 뽑아도 런 결과 난수는 밀리지 않게 하기 위해서입니다. 난수 상태가 세이브에 들어가므로 불러온 뒤 이어 해도 재현됩니다.
- 시작 상태: 나무 25 · 돌 20 · 열매 12, 몬스터 A 2마리 + B 1마리(도감 '획득').

### 몬스터·알
- 9종(A~I), 지역당 3종(일반 2 + 희귀 1). 알 종 = 몬스터 종(1:1).
- 런 성향 값은 침입·운반·대응 3종, 1~4.
- 능력은 '공격' 풀 2개 + '특수' 풀 2개. B안(고정)은 각 풀의 첫 번째.
- 능력 효과: 성향 값 가산 또는 특수 효과(가방칸, 동료 소생, 목격 확률, 파티 다운 감소).
- 알 크기: 종별 기본 크기에서 25% 확률로 한 단계 크거나 작게. 큰 알 → 부화 시 가장 높은 성향 값 +1, 작은 알 → 부화 1런 단축, 손상된 알 → 부화 1런 지연.
- 열매 장비: 일반 열매(열매 3개)로 성향 값 +1, 고급 열매(열매 2 + 고급 재료 1)로 특수 효과. 장착 후 해제 불가, 사망 시 소실.

### 런 스텁 (확률 모드)
- 판정 3단계: **잠입**(침입) → **알 집기**(대응, 목표 둥지마다) → **도주**(운반, 알을 들었을 때만). 각 판정 = 기본 확률 + (파티 합산 성향 값 − 위험도 기준치) × 4%, 10~95%로 제한.
- 위험 요소는 위험도 1당 1개. 각자 깎는 판정이 있고(−10%), 해당 성향 값이 기준치+2 이상이면 상쇄됩니다. 파티 구성으로 위험 요소를 받아칠 수 있게 하려는 의도입니다.
- 잠입 실패 = 경보: 알 집기 −30%, 다운 확률 증가. 도주 실패: 50%로 마지막 알을 떨어뜨리고, 나머지 50%는 알이 손상됩니다.
- 다운 → 소생 판정(기본 45%) 실패 시 사망. 전원 사망이면 들고 있던 알도 잃습니다.
- 목표 둥지는 항상 목격, 나머지 둥지는 50%로 목격(넓은 시야 능력으로 증가). 실패한 런도 목격 정보가 남습니다.
- 가방: 기본 2칸, 소·중 알 1칸 / 대 알 2칸. 탐욕 시 두 번째 알이 가방에 안 들어가면 두고 옵니다.
- 고급 재료: 시도하면 카드에 적힌 양을 확정 획득. 탐욕 추가분은 전멸하지 않았을 때만.
- "시도" = 출동 준비에서 **둥지 공략**을 고른 런. **즉시 탈출**을 고르면 빈 런(보상·생산·부화 진행·보드 갱신 없음). 입장 비용은 빈 런에도 냅니다.
- 고정 수치(성장 대상 아님) 3종의 사용처: 알 감지 배율 = 알을 든 상태의 기본 다운 확률 ×1.5, 알 운반 페널티 = 크기별 도주 감소, 소란도 임계값 = 위험 요소·경보·탐욕·도주 실패로 쌓인 소란도가 100 이상이면 증원 도착(다운 +10%).
- 출동 준비 화면에 파티 성향 합계와 기준치, 위험 요소 상쇄 여부를 보여 줍니다. 결과 화면 하단에 테스트용 판정 확률을 작게 표시합니다.

### 진행자 모드
- 출동 준비 화면에 진행자 입력 패널이 뜹니다. 둥지마다 획득/손상/목격/크기, 몬스터마다 무사/다운 후 소생/사망, 사건 태그(비우면 자동)를 지정합니다. 진행자 패널에는 `?` 둥지의 정체가 보입니다.
- 진행자 모드에선 가방칸·전멸 시 알 상실 같은 규칙을 적용하지 않고 입력 그대로 반영합니다.

### 지역 해금
- 지역 N은 지역 N−1의 고급 재료를 **한 번이라도 얻으면** 보드에 등장하고(해금), 입장할 때마다 그 재료를 `entryCost`(기본 2)만큼 냅니다.

### 두더지 굴 보드
- 매 보드 생성 순서: **수집형**(목격·미획득 알이 있을 때만) → **재료형** → **안전형** → 모자라면 **탐색형**(대체 유형, 위험도 2·둥지 3개)으로 채운 뒤 순서를 섞습니다.
- 수집형: 위험도 3, 둥지 3개(첫 둥지가 `!` 확정), 고급 재료 1. 재료형: 위험도 2, 둥지 2개, 고급 재료 3. 안전형: 위험도 1, 둥지 2개, 고급 재료 1.
- 재료형의 "지금 필요한 고급 재료" = (다음 메인 거점 단계 + 창고 알 중 지금 지을 수 있는 부화장 + 다음 잔성장 단계 + 다음 지역 해금용 1개) − 보유량이 가장 큰 재료. 없으면 해금된 지역 중 무작위.
- 수집형이 아닌 카드에서 확정 둥지는 `✓`(획득한 알)만, 둥지당 35% 확률. `?` 둥지는 그 지역 출현 종 중 희귀도 가중치(일반 1 : 희귀 0.35)로 뽑고, 50%는 흔적 둥지(“습지 계열의 무언가”), 50%는 미확인 둥지(“알 수 없음”). 흔적 힌트는 그 종의 첫 번째 출현 지역 계열입니다.
- 추적 표식: 수집형 대상 선택 가중치 ×4. 보드에 추적 중인 알이 확정 둥지로 하나도 없으면 60% 확률로 그 알이 나오는 지역 카드의 둥지 하나를 확정 둥지로 바꿉니다. 추적은 한 번에 1종만.
- 불운 보정: 희귀 알(C·F·I)이 3보드 연속으로 어떤 둥지에도 안 나오면, 이후 보드마다 가중치 +50%. 등장하면 초기화. 화면에는 보이지 않고 디버그 패널에만 표시합니다.
- 판돈: `?` 둥지 정체 공개 = 돌 4, 공개된 알은 도감에 '목격'으로 등록(이후 확정 둥지 후보가 됨). 보드 다시 뽑기 = 나무 6 + 돌 3. 일반 재료를 쓰게 해서 일반 재료 소비처 역할도 겸합니다.
- 보드는 시도한 런이 끝날 때, 판돈 다시 뽑기, 디버그 재생성 때만 바뀝니다.

### 거점
- 건설 터는 고정 8칸(메인 거점·두더지 굴은 별도). 생산 건물과 부화장이 같은 터를 나눠 씁니다 — 알을 많이 들고 오면 생산 건물 자리와 경쟁합니다.
- 메인 거점 4단계. Lv.1 작업 슬롯 2 · 열매 덤불/벌목장 · 기본 부화장 → Lv.2 슬롯 4 · 채석장 · 습지 부화장(송진 호박 2) → Lv.3 슬롯 6 · 건물 개수 증가 · 대형 부화장(이끼 결정 3) → Lv.4 슬롯 8(흑요 파편 3).
- 생산 건물: 건물당 3칸, 해당 생산 능력 몬스터 1마리당 런마다 4. 생산 건물 업그레이드는 없습니다(체감 없는 수치 강화 배제). 철거 가능(환불 없음).
- 작업 슬롯 = 모든 생산 건물에 배치된 몬스터 수의 상한.
- 자동 노동: 출동 파티가 아닌 몬스터를, 생산 능력이 적은 몬스터부터 건물마다 돌아가며 배치. 수동 노동: 플레이어가 배치하고, 출동 파티에 든 배치 몬스터는 그 런에 생산하지 않음(출동 준비·거점 화면에 경고). 자동→수동 전환 시 현재 자동 배치를 그대로 복사합니다.
- 부화장: 알을 창고에서 꺼내 건설하면 그 터에 들어가고, **시도한 런**이 끝날 때마다 1 진행. 부화 시 몬스터가 생기고 부화장은 사라집니다. 부화한 순간 팝업으로 배정 능력을 공개합니다.
- 생산 틱·부화 진행은 보드 갱신보다 먼저 처리합니다(부화로 도감이 바뀐 상태가 다음 보드에 반영되도록).

### 공용 잔성장
- 4항목: 가방칸 +1(최대 2), 대시 충전 +1(최대 2, 도주 +6%·다운 −3%), 소생 창 연장(최대 2, 소생 +15%), 입장 비용 할인(최대 1, 입장 재료 −1).
- 비용: 대부분 고급 재료, 입장 비용 할인만 일반 재료(나무 20 + 돌 20).
- 모듈을 끄면 구매 단계는 그대로 두고 효과만 0이 됩니다. 켜고 끄며 같은 세이브로 비교할 수 있게 하기 위해서입니다.
- 능력 배정 방식(A/B안) 토글은 이후 부화하는 몬스터부터 적용됩니다. 이미 태어난 몬스터의 능력은 바뀌지 않습니다.
- 현재 모듈 상태는 거점 화면 상단 배지와 디버그 패널에 표시됩니다.
